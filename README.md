# 京津家庭六日游 · 2026.08.17–22

**在线浏览：** https://guoyb001.github.io/family-trip-tj-bj-2026/ （自定义域名 trip.guoyb.cn）

一家四口（夫妻 + 70岁老人 + 初中生）从深圳出发，天津 2 晚 + 北京 3 晚 + 夜班软卧返深。

## 住宿

- **天津 8.17–8.18**（2 晚）：亚朵酒店（五大道小白楼店）
- **北京 8.19**（1 晚）：北京康莱德酒店（国贸/建国门区域）
- **北京 8.20–8.21**（2 晚）：亚朵酒店（前门大栅栏店）
- **8.22 返程**：D927 北京西→深圳北 软卧（4人两包间）

## 如何协作调整

任何人可以提修改建议，三选一：

1. **GitHub Issues（最简单）**：在 [Issues 区](https://github.com/guoyb001/family-trip-tj-bj-2026/issues) 直接写评论或新建 Issue，例如"Day 3 五大道换瓷房子"
2. **网页直接改**：打开网页后，浏览器里 `Ctrl+P` 打印为 PDF 圈出修改处发回
3. **Fork + Pull Request**：技术向家人在右上角 Fork → 修改 → 提 PR
